# 会議AI文字起こし

会議を録音しながらリアルタイムで文字起こしし、終了後にAI（Claude）で議事録を自動作成するWebアプリです。
HTML / CSS / JavaScript のみで動作し、サーバーやビルドは不要です。

## 機能

- **リアルタイム文字起こし**：ブラウザの音声認識（Web Speech API）で発言を逐次テキスト化（日本語・英語・中国語・韓国語）
- **タイムスタンプ・話者名**：各発言に経過時間と話者名を記録（話者は入力欄を切り替えて指定）
- **録音**：会議音声をファイルとしてダウンロード可能
- **一時停止 / 再開**、音量メーター
- **文字起こしの手修正**：各行をクリックして直接編集
- **AI議事録**：Claude が「概要・議題ごとの議論・決定事項・ToDo・保留事項」をMarkdownでまとめる（ストリーミング表示）
- **保存・書き出し**：ブラウザ内に会議を保存、Markdown / テキストで書き出し、コピー

## 使い方

1. マイクを使うため `https://` か `localhost` で開きます。

   ```sh
   cd meeting-transcriber
   python3 -m http.server 8000
   # Chrome で http://localhost:8000 を開く
   ```

2. 「⚙ 設定」で Anthropic APIキー（https://console.anthropic.com で発行）を登録します（AI議事録を使う場合のみ）。
3. 「● 録音開始」→ マイクを許可 → 会議を開始。
4. 「■ 終了」後に「AIで議事録を作成」。

## 対応ブラウザ

- Google Chrome / Microsoft Edge（デスクトップ・Android）を推奨
- Safari は音声認識の対応が限定的、Firefox は非対応です

## 注意事項

- Chrome の音声認識は音声を Google のサーバーに送信して処理します。機密性の高い会議では社内規程を確認してください。
- AI議事録では文字起こしテキストが Anthropic API に送信されます。
- APIキーはブラウザの localStorage に保存されます。共用PCでは使わないでください。
  社内公開する場合は、APIキーをサーバー側に置く中継API（プロキシ）を用意する構成を推奨します。
- 会議を録音・文字起こしする際は、参加者の同意を得てください。
